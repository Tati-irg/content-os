# Рендер каруселей

`node render.js spec.json out_dir` превращает описание карусели (JSON) в слайды 1080×1350 PNG.

- Шаблоны: T01, T02, T03 (вёрстка из `content-os/templates/TEMPLATES.md`), палитра общая.
- Акцент: `wine`, `indigo`, `terracotta` (один на карусель).
- Светлое оформление T03: `"appearance": "light"`. Фон `#F5F5F4`, текст `#2B2C30`. Для плашек выбери один акцент: винный `#7B1E33`, индиго `#2C3566` или терракотовый `#A24F38`. Обложка T03 без фото автоматически светлая, без фотоградиента.
- Типы слайдов: `cover`, `text`, `list`, `quote`, `steps`, `cta`. Неизвестный тип или шаблон даёт BLOCKED (код выхода 3).
- Фото: id из ACTIVE фотобанка (`TP-028`), необязательно `focus: [x, y]` в процентах и `zoom`.
- На обложке с фото (и на CTA T03 с фото) рендер добавляет мягкий градиент со стороны текста. Для конкретного кадра подбери `"photo_gradient": {"angle": 90, "opacity": 0.25, "span": 45}`. Угол CSS задаёт направление затухания, прозрачность на стороне текста — от 0.05 до 0.40, протяжённость — от 10 до 65% вдоль градиента. По умолчанию 0.28 и 55%, направление зависит от макета. Светлый T03 использует светлый градиент под тёмным текстом.
- При просмотре кадра проверь, что градиент поддерживает читаемость текста, остальная часть фото не затемнена, лицо открыто и освещено. При необходимости смени направление, кадрирование или фото. Без фото градиент отсутствует.
- Текст: `**жирный**`, `*акцент*`, пустая строка = абзац. В T03 `[[текст]]` в заголовке даёт плашку‑подсветку.
- Текст сам ужимается до 72%, если не влезает (в отчёте `OVERFLOW`, код выхода 1), и подрастает до 125% на пустых слайдах.
- Рядом со слайдами пишется `render_report.json`.

Пример: `examples/sample_T02.json`. Установка: `npm ci`.
