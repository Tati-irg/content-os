# Журнал решений Таты

Выдержка из журнала, восстановленного на 9 ноября 2026. Ссылки D-xx в модулях относятся к исходным номерам. Здесь собраны решения, нужные для запуска рабочих чатов. Новая запись включает дату, ID, формулировку решения, источник подтверждения и область применения.

| ID | Решение |
| --- | --- |
| D-02, D-05 | В маршруте B проверить текст в 08 до карусели. Если 09 меняет утверждение, вернуть материал в 08. Использовать единые поля передачи. |
| D-04, D-10 | 06 draft v1 и MASTER v1.5 приняты как рабочие версии с последующей проверкой на прогоне. |
| D-06–D-08 | Использовать утверждённые палитру, шаблоны T01–T03 и фото из ACTIVE. |
| D-11, D-15, D-19, D-22 | Сохранять живой голос Таты. Для кейсов использовать собирательные истории. Факты и цифры проверять по первоисточнику. Личные вставки согласовывать отдельно. |
| D-25, D-31, D-32 | Telegram получает самостоятельный текст и обычно обложку вместо альбома. MAX повторяет текст Telegram. |
| D-27–D-30 | Убрать хронометраж терапии из кейсов. Проверять буквальные повторы и повторы по сути. Выбирать мягкий язык по ситуации. |
| D-34 | Проверять темы до показа плана. Большая тема встречается максимум дважды за неделю и трижды за три недели. |
| D-35–D-39 | Подпись «психолог, сексолог, гипнолог». Слайд «Разложим по схеме» для подходящих кейсов и ситуаций про чувства. Финальный вопрос там, где уместен. Голос «пост как сторис». Лицо на обложке в свету. |

## Действующие решения для «Плана на неделю»

Тата подтвердила эти правила 20 ноября 2026 в рабочем чате «План недели». Они применяются при составлении недельного плана.

| ID | Решение |
| --- | --- |
| D-2026-11-20-01 | Одна основная публикация ежедневно в 15:00 МСК. Небольшие дополнительные материалы по необходимости выходят в 18:00 или 19:00 МСК. |
| D-2026-11-20-02 | Недельный план охватывает три цели — охват, доверие и запись. |
| D-2026-11-20-03 | Бесплатные полезности дают ограниченную самостоятельную пользу и не заменяют будущие платные продукты. |
| D-2026-11-20-04 | Мягкое приглашение на бесплатную сессию знакомства (30 минут онлайн) добавляется по контексту. В каждом посте оно необязательно. |

## Архивные сведения

D-13 относилось к конкретному выпуску. D-23 и D-24 описывали планы и эксперименты на момент записи. D-33 фиксировало исторические часы выхода. Эти решения не подтверждают текущие слоты, расписание или одобрение нового материала.
