# Передача результатов между чатами

| Откуда → куда | Что передать |
| --- | --- |
| 01–05 → «План на неделю» (06) | ID исследования, период, выборку, источники, наблюдения и ограничения. Добавь сигналы для 06. |
| 06 + 10 → Тата (GATE 1) | Стратегическую карточку, маршрут A/A-Reel/B/C, проверку тем и ограничения. Передача в производство после подтверждения. |
| 06 → 07 или 09 | Одобренную карточку и версию. A/A-Reel/B получает 07, C получает 09. Для A-Reel см. [передачу Reels](#передача-reels). |
| 07 или 09 → 08 → автор версии | Точную версию, список утверждений, источники и применимые проверки. 08 возвращает ID, вердикт и правки автору. |
| 07 → 09 для маршрута B | Проверенную версию после финальной правки, структуру и текст слайдов, подпись и результаты проверок. Если 09 меняет утверждение, версия возвращается в 08. |
| 07 или 09 → «Запуск» → Тата (GATE 2) | Финальный материал, версию, результаты фактчека и контроля качества, нерешённые вопросы. |
| «Запуск» → ветка публикаций | Для рабочего выпуска передай слот, материал, версию и основания обоих одобрений. В текущем режиме передай только статус локальной проверки. |
| GATE 3 → 01 и реестр | При подтверждённом рабочем выходе верни фактическое время, платформу, URL или ID, опубликованную версию и дату проверки метрик, если применимо. |

Общие поля: FROM / TO, CYCLE ID / CYCLE RUN ID, RELEVANT ID, ASSET VERSION, STATUS, DATE, SUMMARY, REQUIRED ACTION. Сохраняй ссылку на вход, результат и решения Таты. Для отсутствующего обязательного поля укажи `DATA INSUFFICIENT` и причину. Полная схема находится в [HANDOFF_FIELDS](protocols/HANDOFF_FIELDS.md).

Перед GATE 2 проверь для каждой площадки, что её маршрут сохраняет согласованный формат и число вложений. Если формат недоступен, передай отдельную адаптацию на согласование и заблокируй выпуск на эту площадку до подтверждения. В слоте MAX явно укажи согласованный полный самостоятельный текст и число изображений карусели. [Решение о целостности формата](DECISIONS.md#целостность-формата-при-выпуске)

## Передача Reels

Три пакетно записываемых Reels — рабочий ориентир. Выбирай форматы по содержанию и нагрузке без закрепления за днями. [Видеокейс](#передача-еженедельных-кейсов) может входить в этот объём или идти сверх него. В полной рабочей неделе планируй семь основных публикаций. Если Тата отдельно сообщит о нехватке времени, уточни объём на эту неделю. [Решения Таты по Reels](EDITORIAL-C2026-11-19-R01-v1.md#действующие-решения-по-reels)

| Кому | Что передать |
| --- | --- |
| 07 | Одобренную карточку A-Reel и её версию. 07 готовит текст для обложки и подпись. Для Instagram подпись оформляется без хэштегов. |
| 09 | Ссылку на готовое видео со встроенными субтитрами на Google Диске и текст для обложки. 09 готовит обложку. Монтаж и переработка видео возможны только по отдельной просьбе Таты. |
| «Публикации» | Через «Запуск» передай пакет с готовым видео, обложкой с текстом, подписью без хэштегов для Instagram, версией, слотом и основаниями обоих одобрений. До подтверждения рабочего выпуска передаётся только статус локальной проверки. |

## Передача еженедельных кейсов

В карточке кейса указывай происхождение сюжета, точную пометку и для истории из практики результат проверки узнаваемости по сочетанию деталей. Если происхождение неясно, уточни его до выбора пометки. Передавай результат проверки без исходных клиентских данных. [Утверждённые пометки](EDITORIAL-C2026-11-19-R01-v1.md#пометки-для-еженедельных-кейсов)

| Кому | Что передать |
| --- | --- |
| 07, тексты | Подготовь сценарий видеокейса для озвучки Таты. Покажи уточнение запроса, наблюдения и постепенные изменения по D-CASE-03. Конкретные методы и действия психолога согласуй с Татой. Передай происхождение, точную пометку и результат проверки. Включи пометку в текст или подпись и проверь сочетание деталей в финальной версии. |
| 09, «Визуал и видео» | Возьми сценарий, подготовь сюжетные изображения и получи ссылку на озвучку Таты на Google Диске. Собери ролик, добавь субтитры, фоновую музыку с подходящими правами использования и обложку. Возьми точную пометку и результат проверки. Сохрани пометку в согласованном месте и проверь, могут ли добавленные визуальные детали сделать сюжет узнаваемым в сочетании с текстом. |
| «Публикации» | Финальный ролик, обложку и подпись с точной пометкой в согласованном месте, результат проверки для истории из практики и сведения о правах на музыку. Сверь наличие пометки в согласованном тексте, подписи или визуале перед выпуском. |

## Передача Threads

Часы и назначение трёх ежедневных материалов зафиксированы в [журнале решений](EDITORIAL-C2026-11-19-R01-v1.md#threads).

| Кому | Что передать |
| --- | --- |
| 07, тексты | Три самостоятельных задания на 09:00, 13:00 и 17:00 МСК. Если для 13:00 нужно продолжение от аккаунта Таты, подготовь его для согласования вместе с основным текстом. Свяжи с основной публикацией дня максимум одно задание. Сверь самостоятельную задачу каждого материала. Текст и согласованное продолжение в комментарии считай одним материалом. |
| 09, «Визуал и видео» | Если нужен визуал, передай утверждённый угол и версию самостоятельного материала Threads. |
| «Публикации» | Три согласованных текста и их версии с назначением каждого материала. Если согласован комментарий-продолжение, приложи его точную версию и привязку к основному посту. |
| «Исследования и находки» | После выхода собери обезличенные сигналы интереса и примеры языка. Укажи период и объём выборки, отдельно отметь ответы Таты. Несколько комментариев не доказывают массовый спрос. Персональные данные не сохраняй в публичном репозитории. |

## Проверка разнообразия при передаче

Применяй [приоритетное решение Таты](EDITORIAL-C2026-11-19-R01-v1.md#разнообразие-тем).

| Кому | Что передать |
| --- | --- |
| «Исследования и находки» | Сигналы интереса и язык аудитории по разным запросам, с объёмом выборки и ограничениями. Отделяй редакционные гипотезы от наблюдений. |
| 07, тексты | Для каждого задания передай направление, аудиторию, самостоятельную задачу, основание и найденные повторы. Для серии укажи интервал и связь с предыдущим выпуском. |
| 09, «Визуал и видео» | Передай самостоятельную задачу материала и ограничения по повторам сцен. Смена героя или визуального формата не меняет смысл материала. |
| «Публикации» | Передай утверждённые материалы с их самостоятельными задачами. Продолжение Threads в комментарии передавай вместе с исходным текстом как одну публикационную единицу. |
