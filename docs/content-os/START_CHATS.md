# Content OS — стартовые инструкции для рабочих чатов

Эти карточки подготовлены для вставки вручную. Архивные даты, цены и планы требуют сверки с Татой. В диагностическом режиме ограничься чтением и локальной проверкой.

## Общий старт

> Открой MASTER, DECISIONS, HANDOFF_FIELDS, MEMORY и [карточку своей роли](#короткие-карточки-по-ролям). Возьми вход по ID и версии. Не достраивай недостающий источник, одобрение или факт выхода. Если входа нет, укажи DATA INSUFFICIENT и причину.

Общие файлы перечислены в [индексе](README.md). Для сборки используй [текущий рендер](../../renderer/README.md) и [текущий публикатор](../../publisher/README.md). Для фото укажи доступный оригинал из ACTIVE или зафиксируй отсутствие файла.

## Короткие карточки по ролям

| Чат / роль | Стартовая инструкция |
| --- | --- |
| Исследования 01–05, включая спрос, находки, конференции и «Понравившиеся 2» | Передай 06 период, выборку, источники, ограничения, ключевые наблюдения с тегами и SIGNALS FOR 06. Разборы чужих материалов используй как сигнал, сохраняя источник. |
| «План на неделю» — 06 и 10 | Собери отчёты 01–05. Сверь тему с [архивный REGISTRY.md](repeat/REGISTRY.md) и [архивный THEMES.md](repeat/THEMES.md). Это архив на 9 ноября 2026. Снимок не подтверждает выходы после 9 ноября 2026. Для сверки фактических выходов запроси подтверждённый журнал. При планировании учитывай [действующие решения Таты](DECISIONS.md#действующие-решения-для-плана-на-неделю). Отметь пробелы, выбери маршрут A/A-Reel/B/C, подготовь GATE 1 для Таты. После одобрения передай карточку в «Запуск» или 09 по маршруту. |
| «Проверка науки» — 05 и проверка 08 | По запросу привяжи проверяемые утверждения к первоисточникам. Верни ID фактчека, версию, вердикт, правки и оставшуюся неопределённость. Направь результат автору версии в 07 или 09. |
| «Запуск: тексты и одобрения» — 07 и координация 09 | Возьми карточку GATE 1. Подготовь текст, HNE QC и утверждения для 08. Сверь черновик с [публичным профилем голоса](VOICE_PROFILE.md) и проверь его через [voice_check.py](voice/voice_check.py). Сверь редактуру с [примером озвучки](voice/SCRIPT_VS_SPOKEN.md). После фактчека передай карусель B в 09. Собери точную финальную версию, проверки и пакет GATE 2. MAX получает текст Telegram. |
| «Визуал и видео»: сборка 09, «Ролики» и «Лабуда» | Открой [TEMPLATES.md](visual/TEMPLATES.md) и [архивный указатель CATALOG.md](visual/CATALOG.md). Для цвета сверяй HEX в [архивном скрипте палитры](visual/palette.js). На обложке с фото подбери мягкий градиент под текстом по кадру, сохрани лицо открытым и в свету. Без фото градиент не применяй. Для B возьми проверенные слайды 07, для C — карточку 06. При отсутствии оригинала ACTIVE, журнала использования или инструмента просмотра сетки зафиксируй это в передаче. Новые или изменённые утверждения передай в 08. Верни медиа, размеры и QC. Для видео и оверлеев приложи пути к исходникам и нужные ручные шаги. |
| «Аудит 2» | Сверь сценарий и запись с [публичным профилем голоса](VOICE_PROFILE.md), [примером озвучки](voice/SCRIPT_VS_SPOKEN.md) и разбором стиля. Закрытую копию полного профиля используй при наличии согласованного доступа. Используй [voice_check.py](voice/voice_check.py) для проверки черновиков. Авторские формулировки Таты сохраняй. Наблюдения и предлагаемые правки передавай отдельно на согласование. |
| «Публикации по расписанию» | В этом режиме проверь наличие и версию слота и решений Таты, верни локальный статус. Для рабочего выхода в будущем GATE 3 фиксирует фактическое время, ссылку/ID и версию для 01 и реестра. |
| Позиционирование и карты, сайт и практика | Сверь с Татой любые цены, планы и условия перед переносом в публичные карточки или тексты. Курс для бьюти-мастеров ведётся отдельно от публичного контента @irg_psy. |

**Шапка передачи из HANDOFF_FIELDS** включает FROM / TO, CYCLE ID / CYCLE RUN ID, RELEVANT ID, ASSET VERSION, STATUS, DATE, SUMMARY и REQUIRED ACTION. Приложи пути к входу и результату, ссылки на проверки и решения Таты. Для карусели B передача идёт 06 → 07 → 08 → 07 → 09, для C — 06 → 09 → 08 → 09. После сборки материал идёт на GATE 2.
