Исторический порядок: одна строка на пост, включая полезность. Темы рабочей недели вели отдельно и проверяли до показа плана Тате. Для автоматической проверки нужен `repeat_check.py`, который не входит в этот комплект.

Правило: одна большая тема не больше 2 раз за неделю и не больше 3 раз за три недели (эта + две до неё, вышедшее и запланированное). Больше = СТОП, план переделывается до показа Тате.
Полезность к посту того же дня с той же темой пишем с пометкой «серия» в колонке «Серия»: пара считается за один раз.
