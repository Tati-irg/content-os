--------------------------------------------------
1. КЛАСТЕРЫ ПОИСКА
--------------------------------------------------

Искать в четырёх кластерах. Каждый кластер ищется отдельно.

A. ЖЕНЩИНЫ (как самостоятельная аудитория)
— женское желание и его снижение;
— тело, телесность, стыд;
— сексуальность и самооценка;
— оргазм, удовольствие, сексуальные трудности;
— «не хочу мужа», «секс как обязанность».

B. МУЖЧИНЫ (как самостоятельная аудитория)
— мужское желание;
— тревога исполнения, психогенные трудности с эрекцией;
— мужская сексуальность и стыд;
— «она меня не хочет», отвержение.

C. ПАРЫ И ОТНОШЕНИЯ
— кризисы, измены, ревность;
— разные уровни желания в паре;
— коммуникация, конфликты, эмоциональная дистанция;
— «мы как соседи», возвращение близости.

D. СЕКСОЛОГИЯ
— сексологи и сексуальное просвещение для взрослых;
— научно-популярная сексология.

В каждом кластере различать по разделу 7:

DIRECT PROFESSIONAL: тема пересекается с сексуальностью.
ADJACENT PROFESSIONAL: отношения и психология без фокуса на сексе.
CONTENT / MEDIA: блогеры и медиа с большим охватом.


--------------------------------------------------
2. ГДЕ ИСКАТЬ
--------------------------------------------------

Платформы: Instagram, VK, Telegram, Threads.
YouTube только как источник имён (многие воронки начинаются там).

Способы:

1) Стартовый список
   Сначала перепроверить игроков из раздела 21
   (дата сбора там не зафиксирована).

2) Поиск по запросам
   Для каждого кластера держать 10–15 запросов на языке клиента:
   «не хочу мужа», «пропало желание», «секс стал обязанностью»,
   «тревога в постели», «мы как соседи», «сексолог», «парный психолог» и т.п.
   Искать:
   — VK: поиск сообществ и записей;
   — Telegram: каталоги каналов и веб-поиск по t.me;
   — Instagram: хэштеги и поиск по ключевым словам, затем авторы найденных постов;
   — Threads: поиск по ключевым словам;
   — общий веб-поиск по всем платформам.

3) «Снежный ком»
   У каждого найденного конкурента проверить,
   кого он репостит, упоминает, зовёт в эфиры и коллаборации.
   Найденных прогнать через фильтр (пункт 3).


--------------------------------------------------
3. ФИЛЬТР ВКЛЮЧЕНИЯ
--------------------------------------------------

Включать, если всё верно:
— русскоязычный контент;
— тема попадает в один из кластеров;
— аккаунт живой: не меньше 4 публикаций за последние 30 дней;
— аудитория это клиенты, а не коллеги.

Исключать:
— контент для психологов (обучение, супервизии, «как вести практику»);
— магазины, 18+ продукты, эротический контент;
— аккаунты с признаками накрутки (охват и реакции не сходятся с размером);
— аккаунты без публикаций больше 60 дней.

Сомнительных помечать UNCLEAR и показывать Татьяне отдельно.

Размер аккаунта не фильтр, а метка:
— МИКРО: до 10 тыс.;
— СРЕДНИЕ: 10–100 тыс.;
— КРУПНЫЕ: больше 100 тыс.
Маленькие нужны для позиционирования, крупные для content signals.


--------------------------------------------------
4. РАЗМЕР ВЫБОРКИ
--------------------------------------------------

На кластер: 10–15 игроков.
Всего: 40–60.

В каждом кластере должны быть:
— хотя бы 2 платформы;
— хотя бы по одному МИКРО, СРЕДНЕМУ и КРУПНОМУ, если они существуют.

Меньше 5 в кластере: прямо писать «выборка мала»
(см. раздел 9, без выводов о насыщенности рынка).


--------------------------------------------------
5. РЕЕСТР КОНКУРЕНТОВ
--------------------------------------------------

Все найденные лежат в одном реестре.

Для каждого:
— имя, платформа, ссылка;
— кластер (A / B / C / D);
— категория (DIRECT / ADJACENT / CONTENT-MEDIA / UNCLEAR);
— размер (МИКРО / СРЕДНИЕ / КРУПНЫЕ);
— откуда найден (стартовый список / запрос / снежный ком);
— дата, когда найден, и дата последней проверки;
— статус: НОВЫЙ / ОДОБРЕН / ИСКЛЮЧЁН (с причиной).

Полная карточка (раздел 8 и 29) заполняется только для ОДОБРЕННЫХ.


--------------------------------------------------
6. ОДОБРЕНИЕ И ОБНОВЛЕНИЕ
--------------------------------------------------

— Новые игроки получают статус НОВЫЙ и уходят Татьяне списком на ок.
  Татьяна может одобрить, исключить или добавить своих.
— В анализ (разделы 10–31) идут только ОДОБРЕННЫЕ.
— Раз в месяц: проверить, живы ли одобренные, и прогнать поиск заново.
— Исключённых повторно не предлагать, если Татьяна не попросит.


--------------------------------------------------
7. ЧТО НЕЛЬЗЯ
--------------------------------------------------

— брать данные иначе как из публичных страниц и официальных API;
— заходить через чужие или подставные аккаунты;
— подписываться, лайкать, писать конкурентам от имени Татьяны;
— считать реестр полной картой рынка (это выборка, см. раздел 9);
— выдавать сохранения и репосты чужих постов, если источник их не показывает.
