# Шаблоны каруселей T01–T03: чем они отличаются

Цвета у всех одни. Исходное изображение `PALETTE.png` отсутствует. Значения цветов сохранены в [архивном скрипте палитры](palette.js). Шаблон задаёт **вёрстку**. Если два шаблона на эскизе выглядят как один в разных цветах, это ошибка.

| | T01 тёмный редакционный | T02 мягкий экспертный | T03 системный |
|---|---|---|---|
| Референс | ref1 (плашки, пилюли) | ref2 (засечки, фото сбоку) | ref3 (капс, карточки, шаги) |
| Обложка | фото на весь слайд, затемнено, крупный капс снизу, винная плашка | фото на весь слайд, заголовок с засечками сверху слева, короткая подводка снизу, круглая стрелка | фото справа, слева тёмная заливка, капс с плашкой‑подсветкой, рамка «и что из этого следует» |
| Внутренние слайды | «журнальный разворот»: фото полосой слева или снизу, текст на светлой бумаге, заголовок в плашке | светлый фон, фото выходит с края, цитата в облачке, списки с иконками | шапка‑рельс сверху, сетка карточек 2×2, схемы шагов со стрелками, фото только как размытая подложка |
| Шрифт | Montserrat, жирный капс и курсив в плашках | Lora (заголовки) + Inter (текст) | Inter Tight, чёрный капс |
| Навигация | пилюли «психолог · сексолог» / @ник, счётчик‑пилюля 1/7 → | номер 01/08 сверху слева, стрелка в круге | номер в кружке в шапке |
| Фото | крупно, драматично, частично обесцвечено | крупно, светло, «по‑человечески» | человек на обложке, дальше фото уходит в фон |
| Для чего | мифы, провокация, острые темы | физиология, деликатное, «со мной что‑то не так» | чек‑листы, классификации, «как устроено», шаги |

Для сборки используй [текущий рендер](../../../renderer/README.md). Если нужно фото, используй согласованный оригинал из ACTIVE. См. [архивный указатель каталога](CATALOG.md).
