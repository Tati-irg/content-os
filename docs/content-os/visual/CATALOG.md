# Указатель фотобанка

> **Архивный снимок на 9 ноября 2026.** Указатель составлен по восстановленному `photo-bank/CATALOG.md`. Он показывает диапазоны ID из архива. Наличие оригиналов, действующее согласование и историю использования сверяй по рабочему фотобанку.

| Диапазон | Архивный набор | Число записей |
| --- | --- | ---: |
| TP-001–TP-051 | Исходные снимки | 51 |
| TP-052–TP-077 | Сгенерированные кадры | 26 |
| TP-078–TP-093 | Осенняя серия сгенерированных кадров | 16 |

В архиве ACTIVE обозначает согласованные оригиналы, ARCHIVE — прежние наборы, EDITED_PENDING — изменённые версии до согласования. Для материала нужен доступный исходник из текущего ACTIVE. Для изменённой версии проверь согласование на GATE 2.

Из публичного указателя исключены индивидуальные описания кадров, имена файлов и метаданные съёмки. Полный каталог хранится отдельно. Фотографии и журнал использования в комплект не входят.
