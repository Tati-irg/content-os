В новом checkout используй текущие [рендер](../../renderer/README.md) и [публикатор](../../publisher/README.md). Для диагностики ограничься локальной сборкой и проверкой. Обычный dry run публикатора для медиа может создавать внешние контейнеры и загружать файлы.

[Единая схема полей](protocols/HANDOFF_FIELDS.md) применяется ко всем передачам. Для исследовательских входов, актуальной истории выходов, фото и выпусков используй согласованные рабочие источники. Если источника нет, зафиксируй `DATA INSUFFICIENT`. Снимки личных данных, полный архив памяти, ссылки на закрытые чаты и справочные материалы практики хранятся отдельно.

## Повторы и темы для «Плана на неделю»

- [REGISTRY.md](repeat/REGISTRY.md) — исторические темы, кейсы, углы и крючки.
- [THEMES.md](repeat/THEMES.md) — историческая разметка больших тем по неделям.

Оба файла — архивные снимки на 9 ноября 2026. Записи не подтверждают актуальную историю выходов. Используй их для предварительной сверки тем. Запись в плане или отсутствие записи в снимке сами по себе не показывают, вышел ли материал.

## Какие входы нужны отдельно

| Роль | Чего нет в общем комплекте нового checkout |
| --- | --- |
| Исследования 01–05 и «Проверка науки» | Выгрузки постов и метрик, сырые выборки и отчёты, рабочие разборы конкурентов, `liked/INDEX.md`, подборки первоисточников и фактчеки конкретных материалов. Шпаргалка ветки науки находится в восстановленном архиве. |
| «План на неделю» и 10 | Отчёты 01–05 текущего цикла, недельные планы, подтверждённый журнал выходов и корпус исходных текстов в `runs/`. В восстановленном архиве есть `repeat_check.py`. Текстовая проверка этим скриптом требует отдельного корпуса. |
| «Запуск» и «Аудит 2» | Полный `VOICE_PROFILE.md`, `voice/SCRIPT_VS_SPOKEN.md`, `voice_check.py`, разбор стиля и памятка по структуре кейсов доступны в восстановленном архиве. Тексты, записи, фактчеки и карточки конкретных материалов передаются отдельно. |
| Сборка 09, «Ролики» и «Лабуда» | Архив содержит `templates/TEMPLATES.md` и `photo-bank/CATALOG.md`. Для работы с фото и видео нужны оригиналы ACTIVE, исходные записи и актуальный учёт фото. Исполняемый рендер и проверка лиц уже есть в `renderer/`. |
| «Публикации по расписанию» | Нужны пакет конкретного выпуска, слот, финальная версия и решения Таты по GATE 1 и GATE 2. Подтверждённый результат GATE 3 берётся из журнала выходов. |
| Сайт, позиционирование и практика | Справочные материалы и подтверждённые цены, условия и планы ведутся отдельно. |

Ссылки на старые `runs/`, `liked/`, шаблонные PNG и личные материалы в протоколах описывают прежнее окружение. Укажи недоступный вход в передаче по роли.
