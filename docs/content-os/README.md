## Протоколы

Это восстановленные версии на 9 ноября 2026. Они описывают роли, поля, гейты и методы. Архивные команды и упомянутые рабочие материалы описывают прежнее окружение. В новом checkout используй текущие [рендер](../../renderer/README.md) и [публикатор](../../publisher/README.md). Для диагностики ограничься локальной сборкой и проверкой. Обычный dry run публикатора для медиа может создавать внешние контейнеры и загружать файлы.

[Единая схема полей](protocols/HANDOFF_FIELDS.md) применяется ко всем передачам. Для исследовательских входов, реестра повторов, фото и выпусков используй согласованные рабочие источники. Если источника нет, зафиксируй `DATA INSUFFICIENT`. Снимки личных данных, полный архив памяти, ссылки на закрытые чаты и справочные материалы практики хранятся отдельно.
